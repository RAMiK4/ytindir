# cleaner file names, best-quality social downloads

## ✨ New features

- Clean file names: characters that Windows and some file managers don't accept (such as | / : * ? " < >), commas and emojis are removed from file names, without leaving double spaces or dangling dashes behind. Can be turned off in Settings → Folders → "Clean filenames".
- Instagram, X and TikTok now default to their best quality and download without issues: the best dash stream on Instagram, the best source-quality stream on X, and on TikTok the source-quality file for supported videos. When the TikTok source file can't be reached, the next best quality is picked automatically.
- Instagram, X and TikTok downloads are saved with short, meaningful names: username_postid (for example fifaworldcup_DdhJKSdzuMT).
- Redesigned cut screen: the time fields share the screen and open the time keypad (1:30, 90 or 1 30 are all accepted); the keyboard's arrow key applies the time and plays the video from that point on the first press, and moves to the other field on the second; the clock icon puts the video's current position in the field; the end point is previewed from 3 seconds before it, and a wrong time shows a warning.
- Cut and cropped videos are saved as Title_1, Title_2…
- Cropped videos are prepared to play in every player, at a quality close to the source; the audio is kept as it is, without being processed again.
- The notification shows the progress while cutting: elapsed time, size, speed and a filling bar.
- On the cut, crop and preview screens, a video playing in YouTube pauses once the video starts playing.

## 🐛 Bug fixes

- The 1080p limit picked a lower resolution for vertical videos (1080×1920) by mistake; fixed. YouTube Shorts now download at the right resolution too.
- Some TikTok videos couldn't be opened or downloaded; fixed.
- Fixed the log screen turning the app half light when the phone is in light mode.
- X formats that can't be downloaded are no longer offered.

## 🔧 Other improvements

- Every release now includes a universal APK for all devices next to the arm64 APK; in-app updates download the one that fits the device.
- Integrated with the latest YTDLnis version (1.9.1.1). Changes that came with it: running and queued downloads are together on one tab, paused queued items no longer start by themselves, approximate file sizes are shown with "~" on the download card, the update checker also updates yt-dlp, backups can be saved to an SD card too, and fixes to cropping and compatibility mode.
- Some interface improvements
