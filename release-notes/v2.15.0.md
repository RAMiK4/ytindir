## ✨ New Features

- For YouTube links, tapping the quality opens the new advanced quick download list
- Audio-only M4A (source audio), MP3 (Opus → MP3) and Thumbnail (original JPG) download options for YouTube links
- 4K, 2K, FHD and HD quality badges in the quick download options, with file size, codec and frame rate
- New advanced quick download menu inside YouTube (coming in new YouTube Morphe versions)
- The all formats list groups videos with the original audio and dubbed videos separately
- SponsorBlock is back (Settings → Processing, off by default)

## 🔧 Changes

- A cleaner format list: low-quality audio, DRC audio copies and videos below 480p are hidden
- The format filter and format sources are removed
- The old "Quick download" shortcut in the share menu is removed
- Bug fixes
- Other improvements
